--------------------------------------------------
1. CONFIGURATION OBJECTIVE
--------------------------------------------------

The objective of this stage was to configure a centralized infrastructure server providing DHCP and DNS services for the simulated Office Network.

DHCP was implemented to automate workstation IP configuration, while DNS was configured to translate the company's internal application hostname into its IPv4 address.

These services are essential for maintaining reliable network connectivity and access to business resources.

Both services were successfully configured and validated without any reported issues.

--------------------------------------------------

DNS Server: 192.168.10.10

A static IPv4 address was selected to ensure that employee workstations can consistently locate the DHCP and DNS infrastructure server.

The server was successfully configured, and connectivity to the default gateway was verified.

4. DNS CONFIGURATION
--------------------------------------------------

Service: DNS
Service Status: Enabled
Record Type: A

Hostname: portal.lab.test
IP Address: 10.0.0.10

The DNS service translates the internal application hostname into the IPv4 address of the application server.

This allows employee workstations to locate internal resources by hostname rather than requiring manually entered IP addresses.

The DNS service was successfully configured, and the A record was created without errors.
