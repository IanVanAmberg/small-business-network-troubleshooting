1. CONFIGURATION OBJECTIVE
--------------------------------------------------

The objective of this stage was to configure the central router connecting the Office and Application network segments.

The router was assigned two IPv4 interfaces, each serving as the default gateway for its respective subnet.

This configuration establishes the routing infrastructure required for communication between employee workstations, internal network services, and the company application server.

Both router interfaces were successfully configured, activated, and validated without any reported issues.

3. CONFIGURATION PROCEDURE
--------------------------------------------------

The router was configured through the Cisco IOS command-line interface.

Configuration tasks included:

A) Entering privileged EXEC and global configuration modes.

B) Assigning the hostname R1.

C) Configuring IPv4 addressing for both GigabitEthernet interfaces.

D) Assigning descriptions to identify connected network segments.

E) Administratively enabling each interface using the no shutdown command.

F) Inspecting interface status and the routing table.

G) Saving the running configuration to startup configuration.

All configuration commands were executed successfully without errors.
